# OMSCS Tracker

Acompanhamento semanal da candidatura ao OMSCS (Fall 2027).

- `tasks.md`: fonte das tarefas. Marque `- [x]` e faça o commit.
- `index.html`: página do GitHub Pages que lê o `tasks.md` e mostra o progresso.

Para manter a página funcionando, preserve o formato: `## Semana N — datas · tema`, as áreas em linhas `**Área**`, as tarefas como `- [ ]` e a linha `**Entrega:**`.
